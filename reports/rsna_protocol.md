# RSNA pilot v1 protocol

Independent development feasibility experiment, seed 17; source metadata maps 30,000 images, of which 29,684 have Calculated adjudications (12,233 NIH patient prefixes). Exclude 316 unadjudicated images without assigning negative targets. Patient-grouped 70/15/15 partition uses seed 42, with any-positive stratification only at patient partition construction. Each selected development patient contributes one image fixed by image-ID order before stratified sample selection. The resulting image prevalence differs from the full archive: train 149/1,024 positive, validation 37/256 positive.

The selected 1,024 train and 256 validation images alone are decoded. Test partition: 4,595 images; test pixels remain unread and no test predictions are authorized. This is not a Kaggle official split reproduction. The mapping subset_group values are retained without guessing their semantics. No pixel-level duplicate scan was performed.

Classification: no/yes for annotated lung opacity suspicious for pneumonia, not etiological diagnosis. Negatives receive no localization or evidence target. Localization uses the enclosing union of all annotated boxes. Evidence diagnostics only use single-box images with three matched geometric controls (69 train, 24 validation); report actual coverage in the 120-case audit separately.

Native 8-bit DICOM intensities, MONOCHROME1 inversion if encountered, no learned normalization. Annotation dimensions are checked against positive DICOM arrays; negative global labels do not supply dimensions, so negative dimensions come from the decoded array. Frozen 576–1,024 visual token budget. Control rectangles match area, shape, and touched-token count; exclude box plus 10% margin, without ultrasound posterior-column exclusion.

Engineering review: inspected 12 training-only eligible overlays. Image/box alignment appears plausible, with no apparent rescaling mismatch. Some controls cross mediastinum, diaphragm, or other nonlung tissue. Controls and replacement sources are not clinically verified normal lung; this confounds mechanistic interpretation and must not be hidden. No expert-pass marker is issued. This first diagnostic run is allowed to measure that limitation; it cannot automatically authorize RL.

Bounded chain: real-model 16-image smoke → B0 audit → 32-case / 32-update short-fit (requires 10% supervised-loss reduction) → one-epoch B1 SFT (256 updates) → B1 audit on the same frozen 120 validation cases. Classification selection evaluates all 256 validation images. Localization metrics use only positive cases, with the denominator recorded. Posttraining B2–B6 and formal multi-seed runs are disabled.

Checks before launch: 12 CPU tests passed; actual RSNA protocol lock and 1,024-entry training schedule checked, including no localization targets on negative images. Initial preparation attempts failed on missing adjudications and absent dimensions in negative global labels; both were handled explicitly before freezing. A CSV null-to-NaN parsing error was caught in the prelaunch schedule check and fixed by preserving literal JSON null when loading the manifest. These failures launched no GPU training.
