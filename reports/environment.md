# 实际环境（2026-10-05）

按用户后续指令，唯一实验执行主机为 pro5000。GPU 为 NVIDIA RTX PRO 5000 72GB Blackwell ×8；检查时 0/1/2/7 各约 71 GiB 空闲，3–6 有既有高利用率任务。本轮选择 GPU 0 做单卡验证，不修改其他进程。每个训练阶段启动前重新检查剩余显存。

实际存储位于服务器 /data 挂载的 ext4 数据盘（19 TiB，总剩余约 17 TiB），指定目标已通过小型创建/写入/读回探针。数据、模型、缓存、日志、checkpoint、环境均落在该盘，未回退到 home 或根分区。真实部署值在私有 runtime.json 中。

Python 3.12.3，PyTorch 2.7.1+cu128，Transformers 4.51.3，PEFT 0.15.2。单独建立中性环境 r812，通过只读 .pth 复用兼容 v0 的基础包；仅向新环境安装缺少的 PEFT、Arrow 与测试依赖，没有升级原环境。完整关键包版本见 requirements.lock，运行时详情保存在数据盘 outputs/environment.json。

Qwen2.5-VL-7B-Instruct 固定 revision：cc594898137f460bfe9f0759e9844b3ce807cfb5。已有 3B 权重不替代任务要求的 7B。视觉 token 预算 576–1024，实际 grid 在每例存档。

本机为 macOS，当前目录是没有既有代码、提交或远程地址的新 Git 仓库。本机仅整理代码、资料和审核页，不做 GPU 实验。此前在 A100 服务器仅做可用性检查和临时存储探针，没有开始训练；之后依用户指令改用 pro5000。

网络下载保留 TLS 校验，GitHub 连接显式使用本机代理。下载经代理转发至服务器；训练进程设置离线模型模式，不上传图像到外部模型服务。第一次权重下载遇到读取超时，保留失败日志，复用四个完整 shard 并重试剩余 shard。
